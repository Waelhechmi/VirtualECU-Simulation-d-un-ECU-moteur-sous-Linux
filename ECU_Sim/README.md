ECU_Sim – Engine ECU Simulation in C on Linux
1. Project Overview

ECU_Sim is a software simulation of an automotive Engine Control Unit (ECU) designed for learning and prototyping ECU logic using C on Linux. It simulates virtual sensors and actuators, runs a real-time control loop, logs data to CSV, and includes unit and integration tests according to ISTQB standards.

Key features:

Virtual sensors: RPM, throttle position (TPS), temperature

Virtual actuators: fuel injector, throttle, ignition

PID-based control loop

CSV logging for post-analysis

Unit tests, integration tests, and ISTQB-style reporting

Modular structure for easy extension
